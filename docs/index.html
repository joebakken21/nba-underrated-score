Methodology, data sources and limitations

The formula (v2.1)

Underrated Score = (Production Value × Performance Penalty) ÷ max(Investment Index, 5)

Production Value (what a player gives)

  • Efficiency, 35%: true shooting (34), playmaking (23), on/off net rating (43).
  • Role difficulty, 30%: defensive versatility (40), workload (33), lineup strength (27).
  • Versatility, 35%: positional flexibility (34), two-way impact (43), skill diversity (23).

Each component is scaled 0–100 by percentile among scored players.

Investment Index (what a player costs)

  • Financial, 40%: salary as a share of the max (65) and dollars per unit of production (35).
  • Usage, 35%: usage rate (40), minutes (33), touches (27).
  • Recognition, 25%: All-Star votes (40) and awards with a five-year decay (60).

The index has a floor of 5 in the formula, so near-zero cost cannot produce a runaway score.

Performance penalty

Scores are multiplied by 0.3 when net rating is below −10 or TS% is below 45%, by 0.6 when net rating is below −5, and by 0.8 when net rating is negative and TS% is below 52%.

Ratings

2.0 and up: Seriously Underrated. 1.5 to 2.0: Quietly Valuable. 1.0 to 1.5: Fairly Rated. Below 1.0: Properly Rated.

Qualifying gates

30+ games over a full season, scaled to the games played so far, 15+ minutes per game, and a Production Value of 50+.

Data

Stats come from the NBA Stats API via nba_api, are scored by a Python loader (pandas, NumPy) and stored in Google BigQuery. Each loader run also writes the CSV snapshot this page reads, so the page updates when a new snapshot is committed. Players averaging 5+ minutes are scored.

Limitations

  • Salary is an estimated tier from minutes and scoring, not contract data, and every player is measured against one league-wide max.
  • All-Star votes are estimated from past All-Star selections.
  • Defensive versatility, two-way impact, positional flexibility and lineup strength use the closest stats nba_api offers.
  • Early in the season samples are small, so scores move a lot from load to load.
